# 📜 Quote Generator Project  
Simple Quote Generator built using **HTML, CSS, and JavaScript**.  
The project displays random quotes on button click, providing a clean UI and smooth user interaction.

---

## 🚀 Features
- Generate a new random quote with each click.
- Clean and responsive UI design.
- Lightweight and simple — built without any external libraries.
- Well-structured code for easy understanding.

---

## 🛠️ Technologies Used
- **HTML5** – Structure of the page  
- **CSS3** – Styling and layout  
- **JavaScript (ES6)** – Logic for generating random quotes
